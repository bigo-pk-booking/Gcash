# G-Wallet Demo (Android)

A standalone wallet-interface demo for learning and UI prototyping. It is **not affiliated with, connected to, or endorsed by GCash**. It does not process payments, store real balances, or create official financial records.

## Features
- Blue-and-white wallet-style home screen
- Clearly labeled simulated balance
- Sample transaction history
- Delete sample transactions from the local demo screen

## Build
Open this repository in Android Studio and build the `app` module, or run the **Build Android APK** GitHub Actions workflow. The workflow uploads a debug APK as an artifact.

Package: `com.gwallet.demo`
